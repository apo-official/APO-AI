# APO AI — Full Rebuild

This package is a clean rebuild from scratch.

## Included
- ChatGPT-style responsive UI
- APO wing logo
- Mobile sidebar with tap-outside close
- New Chat
- Local chat history
- Suggestion buttons
- Dark/light mode
- Firebase Email/Password authentication
- Google sign-in
- Fast / Medium / High modes
- Mode changing locked until sign-in
- Smooth lightweight animations
- Reduced-motion accessibility support

## Files
- index.html
- style.css
- script.js
- apo-logo.jpg

## GitHub Pages
Upload all 4 files to the ROOT of the `APO-AI` repository.
The homepage file must be named exactly:

`index.html`

## Firebase
For Google sign-in on GitHub Pages, make sure this domain is in:

Firebase Authentication → Settings → Authorized domains

`apo-official.github.io`

## Important
The website frontend and Firebase authentication are implemented.
The AI response is still a demo until a secure server-side AI backend is connected.
Do NOT place a private AI API key in `script.js` or any public GitHub file.
